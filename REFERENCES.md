# NetNova — Technical References

This document lists the official technical documentation referenced for the implementation, configuration, networking and deployment aspects of the NetNova PS-020 project.

## 1. Linux SRv6

- **Linux Kernel — Seg6 Sysctl Documentation**
  https://docs.kernel.org/networking/seg6-sysctl.html

  Provides documentation on Linux kernel SRv6-related system parameters and configuration.

- **Linux `ip-route` Manual**
  https://man7.org/linux/man-pages/man8/ip-route.8.html

  Provides reference for Linux route management, IPv6 routes, SRv6 encapsulation and segment-routing local actions.

## 2. Routing Software

- **FRRouting Documentation — Stable 10.6**
  https://docs.frrouting.org/en/stable-10.6/

  Provides reference documentation for routing software, routing protocols and network configuration.

## 3. Container Infrastructure

- **Docker Engine Networking Documentation**
  https://docs.docker.com/engine/network/

  Provides documentation on Docker networking, container connectivity, network configuration and network isolation.

---

These references are provided for technical background and implementation guidance for the NetNova PS-020 project. Inclusion of a reference does not imply that every documented feature was implemented or tested.
